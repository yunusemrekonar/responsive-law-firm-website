# Responsive Legal Web App

A modern and responsive web application designed for law firms, built with **React.js**. This app serves as a legal services website and includes features such as a dynamic blog, Google Maps integration to display office location(s), a contact form, and dedicated sections for services, about us, and more.

## 🌐 Features

- 🏛️ **About Us Page** – Professional introduction of the firm or legal team  
- 🧑‍⚖️ **Services Section** – List of legal services offered  
- 📰 **Blog Page** – Share legal news, articles, or firm updates  
- 📍 **Google Maps Integration** – Show firm location or multiple branch offices  
- 📬 **Contact Form** – Responsive form for client inquiries  
- 📱 **Fully Responsive Design** – Works smoothly across all devices  
- 🌙 **Modern UI/UX** – Clean and intuitive user interface  

## 🛠 Tech Stack

- **Frontend:** [React.js](https://reactjs.org/)  
- **Styling:** CSS / Tailwind CSS (optional)  
- **Maps:** Google Maps Embed API  
- **Form Handling:** EmailJS / Formspree (optional integration)

## 📁 Pages & Components

- `/` – Home Page  
- `/about` – About Us  
- `/services` – Our Services  
- `/blog` – Blog Listing and Detail Pages  
- `/contact` – Contact Page with Google Maps and Form  

## 🚀 Getting Started

To run this project locally:

### 1. Clone the repository
```bash
git clone https://github.com/your-username/legal-web-app.git
cd legal-web-app

2. Install dependencies
npm install

3. Start the development server
npm start

⚙️ Configuration (Optional)
To enable contact form submissions, integrate with EmailJS or Formspree

Update blog and services content in /src/data or via CMS if integrated
